## Mission

Build the public VexLife Home as a truthful read-only projection of the real
VexLife identity lattice, not as a marketing shell with empty navigation.

The public visitor should be able to perceive:

```text
what VexLife is
how a human and Vex relate
which experiences exist and whom they serve
which features and capabilities are registered
what is current, reference, preview or held
why registries exist and what each registry protects
how Home, Terrain, Guide, Health, recovery and distribution connect
where Vextreme supplies institutional lineage
how to descend to exact public source without loading private Home data
```

The public site demonstrates the architecture before a visitor has installed a
local companion. It does not claim that a model is running, that private Home or
Memory data is loaded, or that registration grants availability or effect
authority.
