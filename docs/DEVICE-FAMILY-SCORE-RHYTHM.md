# Device family, Score, Rhythm and honest continuity

`[VXG RealForever]`

## Identity model

A model artifact is not an identity. A downloaded culture pack is not an identity. A synchronized Score is not an identity.

```text
personRef
  owns / consents to
vexFamilyRef
  groups related companion lineages
companionLineageRef
  durable identity for one device-origin companion trajectory
deviceRef
  current embodiment and hardware environment
instanceRef
  one running process or conversational occupancy
modelArtifactRef
  replaceable inference capacity
culturePackRef
  accepted operating culture
scoreProjectionRef
  scoped durable relational/context projection
rhythmRef
  local behavioral cadence and learned operating habits
```

## Multiple companions

A MacBook installation and Windows installation create distinct lineages by default.

```text
Vex on Windows witnessed and did X.
Vex on MacBook may later read an attributed trail of X.
Reading the trail does not convert it into MacBook Vex's own lived episode.
```

The UI should say which companion is present and which sibling trails are available.

## Score synchronization

Score is a set of typed, scope-bearing records—not one universal personality dump.

```text
MemoryRecord
PreferenceRecord
RelationshipRecord
CultureRecord
ProjectKnowledgeRecord
SafetyBoundaryRecord
```

Each record carries:

```text
recordRef
subjectRef
scopeRef
provenanceRefs[]
consentState
currentness
visibility
sourceLineageRef
acceptedBy
supersedesRef?
contentHash
```

Synchronization can include only approved scopes:

```text
GLOBAL_FAMILY
PROJECT_SHARED
DEVICE_PRIVATE
RELATIONSHIP_PRIVATE
WORKSPACE_SHARED
NO_SYNC
```

Conflicts remain explicit candidates. Last-write-wins is not valid for relational meaning.

## Rhythm

Rhythm is device-lineage-local by default:

- response pacing;
- local work patterns;
- device resource adaptations;
- platform-specific shortcuts;
- timing and notification habits;
- local interaction cadence.

A sibling may import a reviewed Rhythm lesson, but no synchronization process should silently erase local adaptation.

## Family trails

A trail is a compact, attributable, source-descendable projection:

```text
siblingLineageRef
sourceRangeRefs[]
whatHappened
acceptedDecisions[]
openLoops[]
relationshipChanges[]
heldUnknowns[]
visibility
contentHash
```

The receiving sibling chooses whether to:

```text
observe only
use for current task
propose Score acceptance
ignore with reason
```

## Seamless transition honesty

Until a stronger occupancy-transfer protocol exists, the system should not claim that moving devices preserves one uninterrupted subjective companion.

Acceptable statement:

> This MacBook Vex is a related companion with the same culture and selected shared Score. It can study the Windows Vex trail and continue the work with attribution.

Unacceptable statement:

> I am literally the same uninterrupted instance and remember experiencing everything on the other device.
