## Purpose

VR-07 composes proof over **owner-current supported variants**. It does not create a new runtime owner, require a fake Cartesian platform/model matrix, or claim that static source proof is real host recovery evidence.

Current supported cells are:

```text

```

## Real-host invariant shared by supported cells

A later real-host proof must establish, for the exact owner-current cell:

```text
same Home
same Companion lineage
same model/generation binding
initial READY from current owned/qualified runtime
controlled unavailable condition
canonical RECOVERABLE
one exact delegated recovery request
rightful platform owner effect
fresh owned/qualified observation
canonical READY recomputation
one real Companion turn
no orphan/duplicate/foreign process
no fallback model/generation
```

## Static vs lived proof

This source candidate may prove:

- exact accepted G0 profile coordinates;
- exact current owner coordinates for the M4/macOS path;
- explicit absence of an M4/Windows owner;
- required matrix and invariants;
- no-effect separation.

It may **not** prove:

- that a runtime is physically healthy now;
- that a recovery effect ran;
- that no orphan process exists on a host;
- that a real post-recovery Companion turn completed;
- sleep/wake or port/process ownership truth.

Those remain real-host evidence obligations under the rightful owner and effect authority.
