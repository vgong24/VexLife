# Foundation culture coverage map — intention → source → check → evidence

`[VXG RealForever]`

This map exists so Vextreme culture cannot be reduced to inspiring vocabulary while implementation quietly follows unrelated habits.

A principle is considered operational only when all four are named:

```text
intention
→ canonical source or registry
→ deterministic check or test
→ human-readable evidence / return route
```

If a change cannot identify those four, it is not ready to become load-bearing VexLife behavior.

## Feature admission rule

Every registered feature carries:

```text
identity and human purpose
canonical nodes and state owners
actions, permissions and capabilities
localization refs
process/module owners
positive and negative tests
platform applicability
resource/data/effect/concurrency classes
rollback route
Terrain/Health/Guide projection routes
review-lens dispositions
known gaps and held scope
```

For this first public-origin foundation, every foundational feature is bound to all sixteen review lenses. Later work may mark a lens `NOT_APPLICABLE_WITH_REASON`; omission is never a valid disposition.

## What the automated gate deliberately does not claim

Passing `npm run pr-ready` proves the source-managed contracts and deterministic checks in the named environment. It does not by itself prove:

```text
legal clearance in every jurisdiction
security against every unknown attack
native-platform conformance without native evidence
accessibility without rendered/device evidence
model quality or consciousness
public-release approval
merge authority
that generated scaffolds are finished applications
```

Those unknowns remain visible and routed to the proper reviewer rather than silently converted into confidence.

## Cold-reader test

A fresh human or AI should be able to answer, through bounded source descent:

```text
What is this for?
Where is its canonical identity?
Which state owns it?
Which action and permission does it use?
What does it say in each supported language?
Which features and platforms depend on it?
Which tests protect it?
What can fail, recover or remain unknown?
Where is its current human-readable projection?
Who owns the next decision?
```

If those answers require reconstructing the entire repository or replaying a private conversation, the foundation is incomplete.
