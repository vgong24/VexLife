## Current gap

The accepted product already has a release-qualified Windows source-local setup
route, a terminally accepted Windows onboarding practicum, and internal
Distribution Trust release-evidence validation. What is not yet accepted on
`main` is one public, human-first journey that composes:

```text
understand VexLife
→ choose the supported platform
→ obtain one exact open-source release
→ understand verification and consent
→ run one understandable setup front door
→ meet Vex locally
→ recover or uninstall-preserve without losing Home
```

Historical PR #10 remains staged and noncustodial. This claim does not mutate or
silently supersede its page/catalog paths. The new POC is a separately named
onboarding surface with a separately named source family.
