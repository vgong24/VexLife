## Exact source frontier

A proposal is evaluated only from one source-owned current chain:

```text
current G01 conversation head
→ current G02 Score head
→ current G02 semantic-owner head
→ current G03 Daily Dream head
→ exact Daily Stratum
→ exact wake receipt
```

G04 independently asks G01/G02/G03 to verify the historical source identities it consumes. A G04-local hash never authenticates the history it claims to descend from.

Only the exact `carriedCurrentScoreBindings` of the committed Daily Stratum may support a new Stage-A candidate. Held/deferred Score and unresolved open loops remain held. Corrections, supersessions, tombstones and stale semantic authority cannot keep shaping new Rhythm as if current.

## Stable-pattern policy v1

Stage A admits only these generalized classes:

```text
STABLE_COMMUNICATION_PATTERN
REPEATED_CORRECTION_LESSON
RELATIONAL_TIMING_OR_CADENCE
SOURCE_GROUNDED_REASONING_HABIT
WARMTH_CHALLENGE_BALANCE
DURABLE_CONSENT_OR_BOUNDARY_PRACTICE
GENERALIZABLE_CAPABILITY_OR_JUDGMENT
```

At least two distinct exact accepted source-event bindings are required. Duplicate evidence counts once. A one-off event does not satisfy the threshold.

Raw transcript bodies, exact private wording, dates, promises/obligations, account/financial detail, third-party private facts, unresolved material and other exact source details remain excluded. The corpus contains generalized pattern records plus immutable source identities/hashes, never raw conversation bodies.
