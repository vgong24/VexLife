## Human findings consumed

Victor's walk identified three continuity defects / refinements:

1. closing an open Assortment presentation must not make the current semantic context impossible to reopen;
2. Projects / Frontier summary records must remain inspectable for deeper context without silently activating them;
3. Frontier should spatially project its captured pre-admission records as enterable Terrain children without promoting them to Projects.

## Bounded delta

```text
current semantic context -> reusable presentation re-entry action
summary card -> reusable inspect action -> one inspector surface
Frontier captured record -> Terrain child projection -> same inspector
inspection != activation
close != navigate away
Frontier child != Project admission
```

The two Frontier children are the two captured records already shown by the accepted Evolution fixture:

```text
Company People Timeline
System / Resource Health
```

VexVision Android is deliberately not projected as a Frontier child because the accepted fixture classifies it as an existing parallel trajectory rather than captured pre-admission intent.

## Reuse rule

This candidate does not form a second navigation, history, project, Frontier, or state owner. It reuses:

- current Terrain semantic navigation;
- Navigation / Journey;
- the accepted Evolution shell adapter pattern;
- the accepted Assortment fixture and truth-mode boundary;
- the existing Vex companion projection;
- the shared practicum kit.

A small generic Terrain seam lets the current semantic node advertise one optional presentation action. Assortment supplies the action only for contexts it owns. Terrain does not learn Assortment-specific surface IDs.
