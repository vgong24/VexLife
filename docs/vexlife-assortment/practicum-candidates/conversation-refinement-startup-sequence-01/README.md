# VexLife Conversation Refinement — Startup Sequence Practicum 01

[VXG RealForever]

## Purpose

This package is the durable continuation surface for the current VexLife Conversation Refinement work.

It exists so a future human/AI instance can enter from repository source and understand:

- what human outcome is being built;
- which owners are responsible for which part of the circuit;
- what has already been proved;
- what is still unproved;
- how to change and test the code without repeating the harness/carrier mistakes discovered in this lane;
- which run instructions are stable enough to reuse and which are still candidates.

This package is not a second startup owner, a second Vex Family architecture, a second Relay contract, or a replacement for product source.

## Human outcome

After an explicit Send in Conversation, Vex should never appear abandoned.

The intended experience is:

~~~text
Victor presses Send
-> Vex activity appears immediately
-> pulsing white sparkle
-> public <Thinking> / work-trace phases
-> response begins streaming
-> final Vex response becomes durable
-> public trace collapses behind View work trace
~~~

The public work trace is presentation evidence only. Hidden model chain-of-thought is not exposed, and the public trace must not be fed back into later model prompt context.

## Completion order

Prefer:

~~~text
source cause
-> bounded repair
-> deterministic proof
-> exact host source/runtime effect
-> lived human experience
-> pre-merge cleanup
~~~

Do not prefer:

~~~text
broad suite red
-> unrelated fixture cleanup
-> another broad suite
-> another bootstrap wrapper
-> human reruns
~~~

The foreground outcome is the lived Conversation experience. Proof and transport exist to establish it, not to replace it.

## Update rule

Refine this package when new evidence changes the durable route.

Promote something into the runbook only when its state is known:

~~~text
PROVEN
CANDIDATE / NOT YET PROMOTED
FAILED / DO NOT REUSE
~~~

Never convert a plausible command, a PR comment, or a passing synthetic check into a stable run instruction without the corresponding observed effect.
