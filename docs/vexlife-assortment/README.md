## Why this lane exists

Victor and the design team are using the actual VexLife architecture as the substrate for a slow, inspectable Home evolution process:

```text
human intention
-> current canonical owners
-> design discussion / simulation
-> Reference vs Evolution comparison
-> bounded implementation promotion
-> proof / human walk
-> accepted current source
```

This directory preserves discussion intent, checkpoints, migration context, and source-addressable design lineage. It does **not** replace canonical registries, semantic owners, Workgraph state, Purpose Workspace state, Presentation Graph state, Furnishing state, Journal, Memory, or UX Evolution source.
