## Self-hosting Home

The first practicum is intentionally meta: use This Project / VexLife Assortment / Home Blueprint to simulate how a Project is captured, oriented, continued, expanded, reviewed and eventually placed in Home.

This is dogfooding the VexLife grammar, not creating a parallel Journal, Frontier, Projects or Workgraph implementation.
