# Desktop-first execution wave — Windows Home Node and macOS trusted surface

`[VXG RealForever]`

Mobile is deliberately held during this wave.

## Accepted order

```text
private VexLife origin repository
→ foundation port PR
→ independent Vex review
→ accepted universal blueprint + build-health + bridge contracts
→ Windows and macOS candidates in parallel
→ cross-device convergence review
→ mobile planning later
```

## Windows lane

Windows is the first canonical Home Node reference:

```text
local Vex Home
local model/runtime supervisor
Home Bridge gateway
single-writer continuity services
projects, chat, Guide, Terrain and Health
pairing approval and revocation
```

The raw model endpoint remains private/loopback behind the gateway.

## macOS lane

macOS proves two honest modes:

```text
REMOTE_HOME
  operate the named Windows Home Vex through pairing and a capability lease

LOCAL_SIBLING
  create a distinct MacBook companion lineage and local Vex Home
```

HYBRID never silently substitutes one for the other. When Windows is unavailable, the user chooses whether to open the local sibling.

## Shared obligations

Both lanes consume the same:

```text
stable identities and feature registry
state and selector contracts
localization catalogs
Home Bridge envelopes
permissions/capabilities
build-health and review lenses
conformance receipt shape
```

Each lane returns compile, UI, accessibility, localization, security, lifecycle, resource and environment evidence. Neither lane merges itself or declares the other conformant.
