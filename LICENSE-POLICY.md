# VexLife license policy

This policy explains the repository's licensing boundaries. It does not replace,
modify, or add restrictions to the controlling [Mozilla Public License
2.0](LICENSE).

## Project-authored software

Unless a file says otherwise, the MPL-2.0 applies to VexLife project-authored
source code, executable blueprints, schemas, registries, generators, tests,
scripts, documentation that functions as source, and reference implementations.
Generated projections remain rebuildable and are excluded from the canonical
source manifest; that provenance distinction is not itself a license exception.

VexLife uses one software license for this foundation. It is not offered under a
proprietary dual-license or permissive alternative. Any future exception or
dual-license proposal requires an explicit governance decision and legal review.

## Data

Synthetic fixtures and public registries included in this repository may be
distributed with the covered software. The repository license does not place a
public license on a person's conversations, Score, Rhythm, Dream candidates,
private profile, legal evidence, workspace content, credentials, or Vex Home
runtime state. Those private data classes are excluded from this repository.

## Models and training artifacts

Model-provisioning code in this repository is covered software. Model weights,
adapters, optimizer state, training data, and similar artifacts are not included
and do not acquire the MPL-2.0 merely by being used with VexLife. Each external
artifact remains governed by its own license and terms.

notice requirements. Known material is recorded in
[THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md). Unknown or incompatibly
licensed material must not be added.

The MPL-2.0 grants only the patent rights stated in the license and is not a
patent-clearance opinion. It grants no rights in names, logos, or other

Questions about a particular distribution, data set, model, mark, or dependency
should be resolved before that material is added or published.
