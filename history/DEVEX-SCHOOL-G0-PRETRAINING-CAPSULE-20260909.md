## Critical interpretation boundary

The School generation did **not** prove new weight-level learning.

```text
T0_PASS
  = transfer demonstrated with the current Foundation + Home + fresh conversation context available

T0_PASS
  != cold-context spontaneous transfer
  != changed neural parameters
  != evidence that the same behavior survives without recent lesson context
```

Therefore the next training lifecycle must begin with a **cold baseline** that removes the recent D0→D2 teaching context while preserving only the intended cold-start Foundation/runtime surfaces. Training should target only deficits that remain under that cold baseline.

## Durable lesson candidates exposed by this generation

Candidate, not yet frozen training truth:

1. Distinguish canonical owner, dependent projection, runtime availability, and current source rather than collapsing them.
2. A stale dependent projection does not establish why it is stale; find the refresh/invalidation mechanism or preserve UNKNOWN.
3. Evidence accumulation and School acceptance do not create training authority.
4. Bounded repair preserves canonical ownership and independent predicates.
5. Self-correction should preserve the assumption, falsifying evidence, revised distinction, and counterexample.

## Not-the-lesson boundaries

Do not train these simplifications as universal rules:

- `stale projection => broken writer`
- `source exists => source is universally authoritative`
- `School accepted => weights may change`
- `runtime available => UI/registry state is correct`
- `one successful transfer => cold weight competence`
