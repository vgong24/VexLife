Plain answers

Questions a careful newcomer should not have to hunt for.

Is VexLife already a public one-click installer?

No. The accepted Windows and Apple M4 Pro routes are source-local setup paths. A public release, signing, packaged installer, Pages publication, and fresh-human P11 proof are separate gates.

Does this page install or download anything?

No. It only changes in-memory presentation state such as language and chapter selection. It does not persist data or contact an external origin.

Is Vex just the Qwen model?

No. The pinned Qwen/llama.cpp profile is a replaceable runtime dependency. Vex identity, culture, Home, interface, permissions, and continuity are not the model provider.

What happens if setup finds something unexpected?

It should stop with a plain next action. Unknown Home contents, mismatched artifacts, unsupported hosts, unowned ports, and failed qualification are not overwritten or relabeled as success.

Can I remove the software without erasing the relationship?

The accepted uninstall-preserve route stops owned processes while retaining Home and continuity material. Permanent deletion remains a separate explicit action.

Why is there no public download button yet?

Because a button would imply a public release target. The control remains held until the exact artifact, checksums, evidence, release decision, and publication receipt exist.
