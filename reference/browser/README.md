# Browser reference adapter

This is a dependency-free, working reference projection of the universal VexLife blueprint.

It demonstrates:

- stable `data-node-ref` identity on product, screen, region and element surfaces;
- explicit direct and group channels with `Speaker → Recipient` rendering;
- channel-isolated continuity rather than role switching inside an undirected stream;
- universal selection groups;
- semantic journey events and a current screen frame for Vex Guide;
- a draggable, resizable, nonblocking Guide window;
- bottom-only incremental message append;
- English, Chinese and Japanese string projections;
- draggable/collapsible Terrain layout with canonical relationships preserved;
- human-first Health projection.

It is a platform reference, not the universal source of truth. The canonical identities and contracts live under `blueprint/`.
