# Design baseline process

The design process now treats each reviewed prototype as part of an explicit lineage.

```text
human review
→ whole-feedback synthesis
→ preserve / reject / hypothesis ledger
→ candidate prototype
→ baseline-regression qualification
→ human review
→ optional reference-baseline promotion
→ next candidate
```

A **reference design baseline** is not accepted VexLife product source. It is the comparison organism for later design work.

A successor must state:

```text
priorReferenceBaselineRef
preservedSignals[]
explicitSupersessions[]
newHypotheses[]
rejectedRegressions[]
```

Silence is not permission to erase an already-honed behavior.

E2.6 is the current human-approved design reference baseline for this external review lineage.
