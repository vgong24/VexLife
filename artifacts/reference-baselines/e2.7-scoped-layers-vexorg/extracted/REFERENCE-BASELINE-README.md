# E2.6 — human-approved external reference design baseline

E2.6 is the current **reference design baseline** for this external VexLife experience-review lineage.

It preserves the accumulated E1→E2.5 lessons and adds:
- centered five-item journey browsing over full preserved history,
- visible semantic zoom thresholds and user-controlled auto-entry,
- intent-aware zoom trajectory,
- perceptible horizontal sibling shifts,
- active/outside-click presence menu behavior,
- projection workspace tools that do not rewrite canonical relationships,
- Fan / Rings / Carousel organizational projection choice.

`REFERENCE-BASELINE-E2.6.json` is the machine-readable baseline ledger.

Reference-baseline approval is not product-source acceptance.
